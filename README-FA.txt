Darkself - بسته تنظیمات VPS
===========================

فایل‌ها:
- bot.py: سورس با بارگذاری محرمانه تنظیمات از .env
- requirements.txt: وابستگی‌های پروژه
- .env: تنظیمات آزمایشی واردشده توسط شما؛ آن را عمومی نکنید
- .gitignore: جلوگیری از ارسال فایل‌های محرمانه و دیتابیس به Git

راه‌اندازی اولیه روی Ubuntu 24.04:

1) فایل‌ها را در یک پوشه خصوصی قرار دهید.
2) در همان پوشه اجرا کنید:
   sudo apt update
   sudo apt install -y python3 python3-venv python3-pip
   python3 -m venv .venv
   . .venv/bin/activate
   python -m pip install --upgrade pip
   python -m pip install -r requirements.txt
   chmod 600 .env
   python bot.py

نکات مهم:
- اول فقط اجرای آزمایشی را انجام دهید و خروجی خطاها را بررسی کنید.
- فایل .env، فایل bot_data.json و هرگونه session string را برای کسی ارسال نکنید.
- API_HASH و BOT_TOKEN در مشتق‌سازی کلید رمزگذاری دیتابیس استفاده می‌شوند؛ پس بعد از ذخیره سشن‌ها آن‌ها را عوض نکنید، مگر اینکه بدانید باید داده‌های قبلی را چگونه بازیابی کنید.
- قابلیت‌های خودکار پیام‌دهی، عضویت خودکار و ارسال همگانی را فقط برای کاربران/گروه‌هایی که صریحاً رضایت داده‌اند استفاده کنید. تنظیمات پیش‌فرض چند قابلیت Tabchi خاموش است؛ آن‌ها را برای ارسال ناخواسته فعال نکنید.
- این فقط پیکربندی اولیه است، نه ممیزی امنیتی کامل سورس ۱۶٬۷۷۲ خطی. پیش از استفاده واقعی باید مسیرهای ورود سشن، مدیریت از راه دور و ارسال پیام جداگانه بازبینی شوند.
